# Cart-project

This is a simple shopping cart application built using Vue.js and Laravel api. It allows users to add items to their cart, remove items from their cart, and checkout. The application uses session to store the user's cart data.

## Project setup 

```
npm install
```

### Compiles and hot-reloads for development    
```
npm run serve
```

### Compiles and minifies for production    
```
npm run build
```

### Lints and fixes files    
```
npm run lint
```
